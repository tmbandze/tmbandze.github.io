Trabalho

  • Sangue Solidário Doações de sangue com um modelo preditivo Fim de curso

    Sistema de gestão de doações de sangue, com um painel para o SENASA e os hospitais e uma aplicação para os dadores agendarem doações e acompanharem o seu impacto. Inclui um componente preditivo que estuda como converter dadores de reposição familiar em dadores voluntários regulares, tema de investigação ligado ao SENASA.

    Tecnologia
    Spring Boot, arquitectura hexagonal, PostgreSQL com pgvector, JWT, machine learning
    Qualidade
    91 testes automatizados, segurança baseada em JWT

    Ver código no GitHub (Sangue Solidário)

  • StageUP Portal de estágios com machine learning Independente

    Portal de gestão de estágios para a universidade e para as empresas. As empresas publicam vagas e fazem a triagem das candidaturas com uma pontuação de compatibilidade calculada por machine learning; a universidade valida relatórios e acompanha os estágios num painel analítico. Desenvolvido de forma independente e apresentado nas Jornadas Científicas.

    Ver código no GitHub (StageUP)

  • Ntwanano Hinário digital em xitsonga, português e inglês Aplicação móvel

    Aplicação de hinário com letras em xitsonga, português e inglês, que se podem ler lado a lado. Tem modo de projecção para o culto, partilha das letras em imagem, PDF ou código QR, uma biblioteca com hinários em várias línguas, estatísticas dos hinos mais cantados e um quiz de hinos.

  • Java School Tutor de programação que ensina com perguntas Educação

    Tutor de Java com método socrático: guia o aluno com perguntas em vez de entregar a resposta. O backend em Spring Boot funciona como fronteira de confiança e o código dos alunos é executado com Judge0.

    Tecnologia
    Java, Spring Boot, Judge0
    Qualidade
    56 testes no núcleo pedagógico, documentação extensa de arquitectura

    Ver código no GitHub (Java School)

  • Materiais de computação Unidade de Scratch e livros bilingues de história Colégio Dzovo

    Unidade completa de programação em Scratch para a 4.ª a 6.ª classe, com manuais do professor, livros do aluno, avaliações e catálogo de projectos, ligada à feira de ciências de Outubro. Também criei uma colecção bilingue, em português e inglês, de livros de história de Moçambique para a 4.ª e 5.ª classes.

    Âmbito
    Scratch, currículo Cambridge Primary, material bilingue
